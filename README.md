# Server Room Digital Twin

An interactive Streamlit prototype for simulating power, cooling, and temperature behaviour in a data center/server room.

## Features

- Server workload and power estimation
- Heat generation estimation
- Cooling capacity simulation
- Temperature response simulation
- Rack load distribution
- Cooling failure and workload scenarios
- Hotspot analysis
- Current vs proposed configuration comparison

## Tech Used

- Python
- Streamlit
- NumPy
- Plotly

## Status

This is an engineering prototype developed during a hackathon.
Some parts are still under development and may contain bugs.

## How to Run

```bash
pip install streamlit numpy plotly
streamlit run app.py
